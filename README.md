# Tala: Agimat ng Arkipelago

A pixel-art adventure RPG set in a Philippine-inspired archipelago. Play as Tala, sail the
Balangay between islands, recruit companions, forge gear, fish, and follow a five-chapter story.

## Play

Open `index.html` in any modern browser. The whole game, art included, is in that one file.
It works on desktop and phone (touch controls).
